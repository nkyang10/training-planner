# M4 — Evidence enrichment (planned)

Strava OAuth with webhook and bounded sync, GPX/CSV import, `activity_links` with suggested versus
manual matching, TRIMP and HR-based metrics where heart rate exists, confidence labels that state
missing evidence, and a revoke that really deletes.

Manual logging stays first-class (ADR-0003): enrichment is an improvement to the same loop, never a
prerequisite for it. The precision criterion is the one that matters — a wrong auto-link silently
corrupts every derived metric downstream.
