# M1 — Headless planner (active, 5 of 6)

The highest-value milestone, and the only one where correctness is bought cheaply: the planner is a pure
function, so it can be pinned by fixtures and properties before any UI exists.

## State, 2026-11-04

Five criteria are `done` and **the evidence is a machine run, not a document**: `gate:tests` runs the
vitest suite (determinism, properties, diff, CLI) and `gate:golden` runs the golden and mutation suites,
so a claim of done here fails the phase gate the moment it stops being true.

The remaining criterion is the one no machine can close: **a coach has to read three generated plans and
sign off on structure.** The record will live at
`docs/review/2026-11-04-m1-coach-signoff.md` (not linked until it exists - a link to a file nobody has
written yet is a dead link, and the auditor says so); until it exists, M1 stays active and M2 does not
open.

What exists at this point is in [../../review/2026-11-04-m1-implementation-review.md](../../review/2026-11-04-m1-implementation-review.md):
the frozen signature, passes 0–3 plus the subtract-only safety pass, the invariant set with a
deliberately broken plan per invariant, seven golden fixtures, the mutation check that proves a rule change
breaks exactly the fixtures it should, and a CLI that is tested rather than demonstrated.

Entry state: the M0 contracts and gates are green on `main`, and the knowledge bundle they name exists as
34 heuristic files — none of them `curated` yet, which is still M1 work.

Spine: `spine/m1-planner`.

## Why these seven

Determinism and golden plans are the specification; properties catch what fixtures cannot; the diff
generator is what makes a review explainable months later; the CLI is the smallest surface that exercises
all of it; and the coach sign-off is the one criterion no machine can fake.
