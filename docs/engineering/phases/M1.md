# M1 — Headless planner (active)

The highest-value milestone, and the only one where correctness is bought cheaply: the planner is a
pure function, so it can be pinned by fixtures and properties before any UI exists.

Entry state: the M0 contracts and gates are green on `main`, and the knowledge bundle they name exists
as 34 heuristic files — none of them `curated` yet, which is M1 work too.

Exit is the six criteria above, then the flip in one commit (see [README.md](README.md)). Spine:
`spine/m1-planner`.

Why these six: determinism and golden plans are the specification; properties catch what fixtures
cannot; the diff generator is what makes a review explainable months later; the CLI is the smallest
surface that exercises all of it; and the coach sign-off is the one criterion no machine can fake.
