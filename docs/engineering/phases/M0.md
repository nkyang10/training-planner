# M0 — Skeleton and contracts (closed 2026-11-04)

What existed at the close: seven JSON contracts, `schemas/sql/schema.sql` with row-level security and
the tenant guards, four gates in `tools/`, 34 knowledge heuristic files, 35 documents, and `main`
protected with two required checks.

The phase deliberately did **not** include code. "Ships a stub that returns a valid empty plan" from
[milestones.md](../../roadmap/milestones.md) was not attempted, because there is no `package.json` yet.
That was the right trade: the contracts and the gates were the part that is expensive to change later,
and M1 is where they get executed.

Spine: `spine/m0-contracts` (squash-merged, branch deleted).

What M0 taught, one line each: a document that restates a column list rots (23 measured disagreements,
each recorded and decided in [../contract-vocabulary.md](../contract-vocabulary.md)); a gate nobody has
seen fail is not a gate (every tool in `tools/` was red on something real before it was trusted); and a
claim about enforcement has to name the enforcement.
